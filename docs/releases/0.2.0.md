Adds optional live output observation for app integrations.

- `ExecuteOptions.onOutput(value)` receives each script `text(...)` value before execution completes, in arrival order.
- Callback values are independent JSON copies; mutating them does not change collected `result.output`.
- Final output remains available on success, failure, and cancellation. Queued native messages do not invoke callbacks once cancellation begins or execution completes.
- A synchronous callback exception stops the run with `native-error`, preserving output collected so far. Callback return values are ignored; keep callbacks synchronous and brief.
- No native engine, channel, or platform API changes. Existing callers remain compatible.

Validation includes real native QuickJS streaming before a gated host call completes, ordered Unicode/null output, callback mutation isolation, callback exceptions, and cancellation. Release CI reruns the macOS/Linux, native, packed-source, and ASan/UBSan checks. Android builds, physical devices, and Moose integration remain unverified.

This release exercises npm trusted publishing through GitHub Actions with provenance.
