Initial public release for application integration and validation.

- Native QuickJS 2025-09-13, vendored with upstream MIT license, checksum and provenance; Hermes remains the app runtime.
- Dedicated owner thread and fresh runtime per execution; bounded async JSON host tools, output, heap, stack, deadlines and atomic cancellation.
- Public execute/cancel/close API and configurable start/deliver/stop channel for external adapters.
- Expo iOS and Android bindings, native build identity for replay fingerprints, TypeScript declarations and a packed-artifact Expo example.
- Real native engine, TypeScript transport/integration and extracted-package tests. iOS simulator runtime smoke and independent Pi adapter smoke passed.

Android native build/device behavior, physical devices, mobile SQLite replay and active-run reload/background behavior remain unverified. Moose integration validation will follow this release. QuickJS is an in-process capability boundary, not OS isolation.

GitHub release publishing runs the verification matrix before publishing the exact checked tarball to npm with provenance. The initial npm publish requires repository secret NPM_TOKEN or a configured npm trusted publisher.
